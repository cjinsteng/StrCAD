# 보고서 작성 도우미 (진단·검토 보고서용)

여러 장(章)으로 나뉜 **Word(.docx)** 보고서(주 작업)와 한글(.hwp / .hwpx) 보고서(읽기·분석)를 한 화면에서 보면서
**반복되는 내용을 함께 수정**하고, **절 단위로 AI 교정**을 받고,
결과를 **원본 한글 파일에 반영**하는 프로그램입니다.

## 설치 (Windows)

1. Python 3.9 이상 설치 (설치 시 "Add to PATH" 체크)
2. 명령 프롬프트에서:
   ```
   pip install python-docx olefile pywin32
   ```
3. `실행.bat` 더블클릭 (또는 `python report_assistant.py`)

- `python-docx` : Word 파일 읽기·저장·절/표/사진 추가 (필수)
- `olefile` : .hwp 읽기 (필수)
- `pywin32` : 한글 파일에 수정 반영 (한글이 설치된 PC에서만 동작)
- AI 검토 엔진은 ⚙설정(또는 AI 검토 탭의 "엔진 변경")에서 고릅니다. 아래 "AI 엔진" 참고.
- StrCAD 런처에서는 **Report Design** 카드로 실행됩니다.

## AI 엔진

| 엔진 | 비용 | 특징 |
|---|---|---|
| **Claude** (Anthropic API) | 유료 (API 키 필요) | 검토 품질이 가장 좋음. 긴 절도 한 번에 검토 |
| **Ollama** | 무료 | 내 PC에서 실행, 인터넷 불필요, 보고서 내용이 외부로 나가지 않음 |
| **OpenAI 호환 서버** | 무료/유료 | LM Studio, vLLM 등 `/v1/chat/completions` 를 지원하는 서버 |

### Ollama 설정 (무료)
1. https://ollama.com/download 에서 설치 → 실행 (작업표시줄에 아이콘)
2. 명령 프롬프트에서 모델 내려받기 (한 번만):
   ```
   ollama pull exaone3.5:7.8b
   ```
   - `exaone3.5:7.8b` : LG AI연구원 모델, 한국어 우수, 약 5GB — 일반 PC 권장
   - 그래픽카드 메모리 16GB 이상: `qwen2.5:14b`, `gemma3:12b` 도 좋음
3. 프로그램 ⚙설정 → AI 엔진 "Ollama" → "설치된 모델 불러오기" → 모델 선택 → "연결 시험" → 저장

참고: 내 PC 모델은 Claude보다 느리고(그래픽카드 없으면 절 하나에 수 분) 기술 내용 검토는 약합니다.
오타·띄어쓰기·표현 교정 위주로 쓰고, 긴 절은 "하위 절 포함"을 끄고 작은 절 단위로 검토하세요.
본문이 길면 자동으로 여러 번에 나눠 보냅니다(문맥 길이 설정에 따라).

## Word 와 한글

| | Word (.docx) — 주 작업 | 한글 (.hwp/.hwpx) — 분석 |
|---|---|---|
| 읽기·번호 검사·AI 검토·동일 내용 찾기 | ✔ | ✔ |
| 문단 수정 → 원본 반영 | ✔ (바로 저장, Word 불필요) | ✔ (한글 자동화) |
| 새 절·하위 절·문단·표·사진 추가 | ✔ | — (한글→Word 변환 후) |

**한글→Word 새로 만들기**: 리본 버튼. 한글의 'Word로 저장'은 줄·표가 흐트러지기 쉬워서, 프로그램이 한글 원본(.hwp)을
직접 읽어 Word 를 새로 만듭니다(한글 프로그램 필요 없음). 원본과 같게 맞추는 것:
쪽 크기·여백·머리말/꼬리말 거리·쪽 나누기(→ 한 쪽에 들어가는 내용이 한글과 비슷), 글꼴(한글/영문)·크기·진하게·색·장평·자간,
문단 정렬·여백·들여쓰기·문단 간격·줄 간격, 표 칸 너비·셀 합치기·테두리(이중선 등)·배경색, 그림(원본 크기), 머리말/꼬리말과 쪽 번호.
- 한글 그리기 개체(그림 위에 겹쳐 그린 선·글상자)는 Word 로 옮길 수 없어서, 그림만 넣고 그림 안 글자는 그림 아래 작은 주석으로 남깁니다.
- 줄 간격 100% 미만(빽빽한 출력물 등)은 Word 에서 글자가 겹치므로 100% 로 맞춥니다.
- 한글 작업의 수정 대기·AI 결과는 가져가지 않습니다. Word 작업 상태는 `보고서도우미_작업상태_Word.json` 에 따로 저장됩니다.

### 절·표·사진 추가 (Word)
- 왼쪽 트리에서 절을 **우클릭** → "이 절 뒤에 새 절 추가(5.5)" / "하위 절 추가(5.4.3)" / "이 절 끝에 표·사진 추가"
- 본문 문단을 **우클릭** → "아래에 문단/표/사진 추가"
- 리본 "추가 (Word)" 그룹 버튼도 같음 (선택한 절/문단 기준)
- **글씨체·문단 모양 유지**: 새 제목은 같은 단계 기존 제목(5.4 → 5.5 는 5.4 모양), 새 본문은 그 절의 본문, 새 표는 앞쪽 기존 표의 테두리·셀 서식, 캡션은 기존 `<표 5.1 …>` / `<그림 5.1 …>` 문단을 복사해서 글만 바꿉니다.
- **번호 자동**: 새 절 번호, 표·그림 번호는 자동. 중간에 넣으면 뒤 절 번호(5.5→5.6, 5.5.1→5.6.1)와 같은 장의 뒤 표·그림 번호를 하나씩 밀어 줍니다(변경 목록에 표시).
- **그림**: 본문에 실제 그림이 보입니다(본문 폭 대비 크기 그대로). 넣을 때 본문 폭·쪽 높이를 넘지 않게 자동으로 맞추고,
  그림을 더블클릭/우클릭 → "그림 크기"(cm 또는 본문 폭 %)·"본문 폭에 맞추기".
- **Ctrl+V**: 화면 캡처나 복사한 그림(또는 탐색기에서 복사한 그림 파일)을 선택한 문단 아래에 붙여 넣습니다. 리본 "그림 붙여넣기"도 같음.
- **표 편집 창**(Word [표 레이아웃]과 같은 도구): 위/아래 행 삽입, 왼쪽/오른쪽 열 삽입, 셀 내용·행·열·표 삭제,
  셀 병합·분할, 자동 맞춤(내용/본문 폭/열 너비 고정), 높이·너비(cm), 행 높이·열 너비를 같게, 맞춤 9방향, 머리글 행 반복.
  칸 클릭=선택, Shift+클릭 또는 끌기=여러 칸 선택.
- 문단 수정 창의 '저장'은 변경 목록에 넣는 것이고, **Ctrl+S**(파일에 반영·저장)를 눌러야 Word 파일에 들어갑니다.
- 표는 화면에 실제 칸 모양으로 보입니다. 칸을 더블클릭하거나 표 위 **✎ 표 편집**을 누르면 칸 모양 그대로 입력하는 창이 열립니다
  (Tab 다음 칸, Enter 아래 칸, "＋ 행 추가"). 새 표를 넣으면 이 창이 바로 열립니다.
- 추가한 내용은 "파일에 반영·저장"을 눌러야 Word 파일에 저장됩니다(원본은 `_백업`에 먼저 복사). 저장 전 닫으면 저장할지 묻습니다.
- 잘못 넣은 것은 우클릭 → "새로 넣은 이 문단/표/그림 삭제".

참고: 제목 번호를 글자로 쓴 보고서(예: "5.4 구조안전성 검토")를 기준으로 합니다. Word 자동 번호 매기기로 번호를 붙인 문서는 장·절 인식이 되지 않습니다.

## 사용 순서

1. **📂 한글 열기** 또는 **📂 Word 열기** → 1장~8장 파일이 들어있는 폴더 선택
   - 한글 작업과 Word 작업은 따로 합니다(한 번에 한 형식). 헤더에 "한글 작업 / Word 작업"이 표시됩니다.
   - 한글 작업: 읽기·번호 검사·AI 검토·동일 내용 수정 반영 / Word 작업: 여기에 더해 절·표·사진 추가
   (파일 이름이 아니라 본문의 "제N장" 기준으로 정렬됩니다)
2. 왼쪽 트리에서 절(예: 5.4.1)을 클릭 → 가운데에 본문·표 표시
3. 수정
   - 문단(표 셀 포함) **더블클릭 → 수정 → 저장**
   - 같은 문구/비슷한 문단이 다른 장에도 있으면 **"다른 곳도 함께 수정할까요?"** 창이 뜹니다.
     체크된 항목만 함께 수정됩니다(미리보기에서 바뀌는 부분 확인).
4. **AI 검토** 탭 → "▶ 이 절 AI 검토" → 제안 목록에서 선택 적용 / 무시
   - 주황색 = AI가 지적한 부분, 보라색 "의견" = 직접 바꿀 문구 없이 확인을 요청한 항목
   - AI 제안을 적용할 때도 다른 장에 같은 문구가 있으면 함께 수정 제안
5. 수정한 문단은 노란색으로 표시되고 **변경 목록**에 쌓입니다. (아직 원본은 그대로)
6. **✔ 파일에 반영·저장** → 원본을 `_백업` 폴더에 복사한 뒤 Word 파일은 바로 저장, 한글 파일은 한글 자동화로 찾아 바꾸기 → 다시 읽어서 검증

작업 중인 변경 목록과 공통 항목은 폴더의 `보고서도우미_작업상태.json`에 자동 저장되어,
다음에 같은 폴더를 열면 이어서 작업할 수 있습니다.

## 그 밖의 기능

| 탭/버튼 | 내용 |
|---|---|
| **번호 검사** | 장 번호와 다른 절 번호(제5장 안의 6.3.2), 중복·누락된 절 번호(5.1.5 두 번), (1)(2)·①② 항목 순서, `<그림 5.1>` 캡션 번호. "제안대로 수정"으로 바로 고칠 수 있고, 다른 곳에서 그 번호를 참조하면 함께 수정 제안 |
| **반복 문단 불일치** | 여러 장에 반복되는 문단 중 내용이 조금 다른 것(예: 1장 요약 "16년 경과" vs 5장 "17년 경과")을 찾아 한쪽으로 맞추기 |
| **동일 내용** | 클릭한 문단과 같은/비슷한 문단이 보고서 어디에 있는지, 무엇이 다른지 비교 |
| **공통 항목** | 과업명·위치·연면적·준공연도·fck 등 자동 추출. 사용처 수와 "비슷하지만 다른 표기(⚠)" 표시. "값 변경…"으로 전체 일괄 변경 |
| **변경 목록** | 반영 대기 중인 수정 · 취소 · CSV(엑셀) 내보내기 |

## 한글 반영 방식과 한계

- 각 수정은 문서에서 **한 곳에만 있는 짧은 문구**로 바꿔서 한글의 "모두 바꾸기"로 적용합니다.
  글자 서식(굵게, 색 등)은 대부분 유지됩니다.
- 다음 경우는 자동 반영하지 않고 **"수동 처리"** 목록으로 남깁니다(CSV로 내보내기 가능):
  - 같은 문구가 문서에 여러 번 있고, 앞뒤가 탭·표·그림 경계라 위치를 특정할 수 없는 경우
  - 탭/줄바꿈을 추가·삭제한 경우, 바뀐 부분이 아주 긴 경우(250자 초과)
- 반영 후 파일을 다시 읽어 실제로 바뀌었는지 확인하고, 확인되지 않은 문단은 변경 목록에 그대로 남습니다.
- 반영할 파일은 한글에서 **닫은 상태**로 진행하세요.
- 한글 보안 모듈 창("파일 접근 허용")이 뜨면 "모두 허용"을 누르세요.
- 원본은 항상 `_백업\파일명_날짜_시간.hwp` 로 먼저 복사됩니다.

## 읽기 한계

- 암호/배포용 문서는 읽을 수 없습니다.
- 그림(이미지)·수식은 표시되지 않습니다. 글상자 안 글자는 회색 기울임체로 표시됩니다.
- 머리말/꼬리말/각주는 화면에 보이지 않습니다(반영 시 중복 검사에는 포함).

## 파일 구성

- `report_assistant.py` : 화면(UI)
- `report_core.py` : 동기화·번호 검사·AI 검토·한글 반영 로직
- `hwp_reader.py` : .hwp / .hwpx 읽기
- `docx_doc.py` : Word 읽기, 서식 유지 글자 수정, 절·문단·표·사진 추가
- `hwp_to_word.py` : 한글 원본 → 깔끔한 Word 새로 만들기
- `docx_table.py` : Word 표 레이아웃(행·열 삽입/삭제, 병합·분할, 자동 맞춤, 크기, 맞춤)
