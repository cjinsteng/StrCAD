# StrCAD 현장조사 — 휴대폰·패드 앱

PC(CAD Analysis)에서 만든 **현장조사 파일(.strsv)** 을 휴대폰·패드에서 열어 PC와 같은 화면으로 조사하고,
같은 파일을 PC로 돌려보내면 PC DB에 합쳐집니다. 설치형 웹앱(PWA)이라 앱스토어 없이 홈 화면에 설치됩니다.

## 쓰는 방법 (파일로 주고받기 — 현장에서 인터넷 없이)
1. PC: 현장조사 탭 › **📱 모바일로 내보내기** → `프로젝트_현장조사.strsv` (같은 프로젝트로 저장된 모든 층 + 사진)
2. 파일을 휴대폰으로 보냄 (카카오톡 나에게 보내기 · 메일 · 구글드라이브 · USB)
3. 앱 › **📂 조사 파일 열기** → 층 넘기기(‹ n/N ›), 도면 LIST
4. 조사: **검측점**(탭) / **구간**(같은 부재 위 두 번 탭) → 번호가 붙고 아래(패드는 오른쪽)에 입력란
   - 각 칸을 누르면 선택 목록(도면값 · 최근 입력 · 기본 목록 · 내 목록) / 직접 입력
   - 철근 → I단·중앙·J단 표, 칸을 누르면 개수·규격(D/HD/SHD/UHD)·직경·간격 선택
   - 사진: 📷 촬영 / 🖼 앨범 (1600px로 줄여 파일 안에 저장)
   - ✎ 편집 → 💾 저장 (저장 전에는 반영되지 않음)
5. 메뉴 › **💾 저장/공유** → 카카오톡·메일 등으로 PC에 보냄 (공유가 안 되는 브라우저는 다운로드)
6. PC: 현장조사 탭 › **📥 모바일 DB 가져오기** → 위치별로 더 최근에 고친 쪽이 반영, 휴대폰에서 지운 위치는 삭제,
   사진은 `~/.strcad/photos/프로젝트/층/` 에 저장. 같은 파일을 두 번 가져와도 중복되지 않습니다.

작업 중인 내용은 휴대폰에 자동 저장됩니다(앱을 닫았다 열면 **↺ 이어서 하기**).

## 사무실에서 바로 연결 (같은 Wi-Fi)
PC: 현장조사 탭 › **📶 Wi-Fi 연결** → 표시된 주소(예: `http://192.168.0.12:8765`)를 휴대폰 브라우저에 입력
→ **PC에서 받기** / 메뉴 › **PC로 보내기**. 파일을 옮길 필요가 없습니다. (Windows 방화벽: 개인 네트워크 허용)
이 방식은 PC와 연결되어 있을 때만 앱이 열립니다.

## 현장(오프라인)용으로 설치하기
홈 화면 설치·오프라인 실행은 브라우저 규칙상 **https 주소**에서만 됩니다. 이 `mobile` 폴더를 https로 올리세요.
- **GitHub Pages(무료)**: 저장소를 만들고 `mobile` 폴더 안의 파일을 올림 → Settings › Pages › Branch: main
  → `https://<아이디>.github.io/<저장소>/` 를 휴대폰에서 열기
- 회사 내부 웹서버(https)에 폴더 그대로 복사해도 됩니다.
- 설치: 아이폰 Safari › 공유 › **홈 화면에 추가** / 안드로이드 Chrome › ⋮ › **앱 설치**
한 번 열면 필요한 파일이 저장되어 이후에는 인터넷 없이 실행됩니다. 조사 데이터는 서버로 올라가지 않습니다.

## 파일 구성

`vendor/sql-wasm.js` `vendor/sql-wasm.wasm` — sql.js 1.10.3 (SQLite WebAssembly, MIT)

## .strsv 형식 (SQLite)
`meta`(프로젝트·용도·선택목록) · `sheets`(층별 도면: 부재 중심선·기둥·배경선) ·
`surveys`(uid, updated, deleted, rec=기록 JSON) · `photos`(uid, 이름, BLOB)
