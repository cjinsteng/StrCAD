# StrCAD 검토자 협업 서버 — 설치·운영 안내

여러 검토자가 같은 현장조사를 함께 하도록 조사 내용을 모아 두는 서버입니다.
- 오프라인에서 작업 → 연결되면 앱 위쪽 **🔄 공유** (연결 중에는 10초마다 자동)
- 다른 검토자의 기록·스케치·도면은 **보기만** (앱에서 막고, 서버도 거부)
- 데이터(계정·기록·사진)는 서버 PC의 데이터 폴더 한 파일(`strcad_collab.db`)에 저장 → **백업은 이 파일만 복사**

## 1. 서버 켜기 (둘 중 하나)
**A. StrCAD 프로그램에서** — CAD Analysis › 현장조사 › 👥 검토자 협업 › [서버 켜기]
 (프로그램을 닫으면 서버도 꺼짐. 잠깐 쓸 때)

**B. 계속 켜 두기 (회사 PC·서버)** — 파이썬 3.10 이상만 있으면 됨 (추가 패키지 없음)
```
python collab_server.py --port 8780 --data D:\StrCAD협업
```
또는 `StrCAD_협업서버.bat` 더블클릭. 창에 **주소**와 **팀 코드**가 나옵니다.
Windows 방화벽이 물으면 '허용'. 회사 서버라면 작업 스케줄러에 '시작 시 실행'으로 등록하세요.

## 2. 현장(모바일 데이터)에서 접속하려면
사내 Wi-Fi에서는 `http://서버IP:8780` 그대로 됩니다. 밖에서 쓰려면:

| 방법 | 장점 | 준비 |
|---|---|---|
| **Cloudflare Tunnel (추천)** | 포트 개방 없이 https 주소, 휴대폰에 앱 설치 불필요 | 서버 PC에 `winget install --id Cloudflare.cloudflared` |
| Tailscale | 회사 밖에서 사내망처럼, 외부 공개 안 됨 | 서버 PC·휴대폰 모두 Tailscale 앱 설치·로그인 |

**Cloudflare 빠른 시작** (계정 없이 바로):
```
cloudflared tunnel --url http://localhost:8780
```
→ `https://xxxx.trycloudflare.com` 주소가 나오면 그 주소를 앱에 입력. 
※ 빠른 터널은 켤 때마다 주소가 바뀝니다. **고정 주소**가 필요하면 Cloudflare 계정 + 회사 도메인으로
'이름 있는 터널(named tunnel)'을 만들어 `https://strcad.회사도메인` 처럼 쓰세요 (Cloudflare Zero Trust › Tunnels).

## 3. 계정
- **처음 가입한 사람 = 관리자** (팀 코드 없이 가입)
- 다른 사람: 앱 › 메뉴 › 👥 협업 › 가입 — 이름·아이디·비밀번호 + **팀 코드**
- 관리자: 👥 협업 › **인원 관리** — 계정 추가, 사용 중지/재개, 비밀번호 초기화, 관리자 지정, 이름 변경, 팀 코드 변경
- 사용 중지하면 그 사람의 로그인이 바로 끊깁니다. 그 사람이 남긴 기록은 그대로 보입니다.

## 4. 쓰는 순서
1. 한 사람이 조사 파일(.strsv, PC 내보내기 또는 휴대폰에서 만든 것)을 열고 👥 협업 › **협업 프로젝트로 올리기**
   (PC에서는 👥 검토자 협업 › '지금 PC 프로젝트를 협업 프로젝트로 올리기')
2. 다른 검토자는 👥 협업 › 프로젝트 목록에서 열기
3. 각자 조사 → 🔄 공유 (오프라인이면 숫자 배지로 대기 건수 표시, 연결되면 다시 누르기)
4. PC로 모으기: CAD Analysis › 👥 검토자 협업 › 프로젝트 고르고 **PC DB로 가져오기**

- 번호가 겹치면(둘이 오프라인에서 같은 번호) 나중에 공유한 쪽 번호가 다음 번호로 바뀌고, 사진 이름도 함께 바뀝니다.
- 원본 사진은 각자 휴대폰에 그대로 있고, 서버에는 화면용 축소본이 올라갑니다 (원본은 기존처럼 PC Wi-Fi 전송/폴더 복사).
- 도면 축척 맞추기는 다른 검토자 기록이 없는 도면에서만 됩니다.
