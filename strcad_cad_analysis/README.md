## 사용 흐름
1. 📂 DXF 열기 → **전체 도면 미리보기**. 평면이 자동으로 찾아져 파란 점선 박스(평면 1, 2…)로 표시됨
   - 박스 클릭 = 그 평면만 분석 · 드래그 = 원하는 영역 직접 지정 · 박스 밖 더블클릭 = 전체 분석
   - 다른 평면은 [⬚ 영역 선택]으로 돌아가 다시 고름
2. 레이어 자동 분류 → **레이어 매핑 확인 창** (수정한 매핑은 다음부터 기억)
   - 레이어가 엉망인 도면: 해당 레이어를 **'형상 자동판별'** 로 지정 (구조 레이어를 하나도 못 찾으면 자동 지정)
3. 확인 후 분석 → 기둥=점, 거더/보/벽=중심선, **부재끼리 절점 공유**
4. 클릭 → 부재명, 종류, 크기, L(절점 i–j), ln(순경간), 시·종점 X/Y, 절점 번호/공유 부재 수
5. 수정 → '부재 정보' 탭: 이름 ✎, **종류 콤보박스(기둥↔벽↔보↔거더)** · '편집' 탭: 추가/이동/삭제
6. 💾 DB 저장 / 📁 DB 불러오기 (원본 DXF 없이도 다시 열림) · 📤 CSV/JSON/중심선 DXF

## 편집 탭
| 도구 | 동작 |
|---|---|
| 선택 | 클릭 선택, Delete 키 삭제 |
| 이동 | 절점(□) 드래그 → 다른 절점에 놓으면 **합쳐짐(공유)**, 부재 위에 놓으면 T접합. 부재 몸통 드래그 = 부재 이동 |
| 기둥 추가 | 클릭 위치(절점·그리드 교점·부재 위 스냅)에 b×h 기둥 |
| 선부재 추가 | 시점→종점 클릭. 절점/그리드 교점/부재 위에 스냅되어 자동 연결. Shift=좌표축 방향 |
| 삭제 | 클릭한 부재 삭제 |
- 선택 부재: 크기 수정, i단/j단 절점 분리 · Ctrl+Z/Ctrl+Y 되돌리기 60단계 · [절점 다시 연결]
- T접합 절점은 끌면 모부재를 따라 미끄러지고, 멀리 끌어내면 접합이 풀림. 곡선부재 절점은 고정.

## 절점 공유 규칙
- 기둥 안/옆에 끝나는 보·거더·벽 → **기둥 중심 절점** (부재선이 약간 꺾일 수 있음 — 의도된 동작)
- 끝점끼리 만나는 부재(모서리, 교차) → 하나의 절점
- 다른 부재 옆면에 끝나는 부재 → 그 부재 축 위의 **T접합 절점** (모부재를 따라 움직임)
- 기둥/벽 돌출부 때문에 짧게 끝난 보·거더 → 축 방향으로 최대 1.2 m 연장해 연결
- L = 절점 i–j 거리, ln = L − 양단 지지면 거리(기둥 외곽 또는 직교부재 폭/2)

## DB
`~/.strcad/cad_analysis.db` (SQLite). `analyses`(분석 전체, 압축 JSON) + `members`(부재 평면 테이블:
kind, name, size, 길이, 좌표, 절점 i/j) — 다른 모듈에서 `SELECT * FROM members WHERE analysis_id=?` 로 조회 가능.

조작: 휠=확대/축소, 드래그(좌/우/휠버튼)=이동, 클릭=선택.
표시: 실선=도면에 표기된 이름, 점선=추정 또는 미표기.

## 형상 자동판별 기준 (레이어 정보 없을 때)
- 기둥: 닫힌 사각형(긴변 ≤1600, 짧은변 ≥200, 비 ≤3) 또는 원
- 평행선 쌍: 두께<150 → 벽 · 양단 기둥 연결 & 폭≥300 → 거더 · 기둥 사이 얇은 부재 → 벽
  · 거더에 걸림 & 폭 150~600 → 보 · 나머지 두께≤350 → 벽
- 근처에 부재명(G1/B1/W1…)이 있으면 표기가 우선. 판별 결과는 ◆ 표시 + 비고에 근거 기록
- car1을 레이어 섞어서 시험: 주 골조는 거의 그대로 복원, 벽·옹벽 주변은 일부 종류 오판 → 종류 콤보박스로 수정

## 알고리즘 요약
- **기둥**: 기둥 레이어의 닫힌 외곽(LINE 루프/폴리라인/원) → 최소외접사각형으로 b×h·각도, 중심=점.
  기둥 레이어에 없지만 `C1` 표기 옆에 있는 벽·보 레이어의 작은 닫힌 사각형도 기둥으로 인식(비고에 표시).
- **선부재**: 평행선 쌍 → 중심선 + 폭. 좁은 쌍부터 매칭하고 한 선의 같은 구간은 한 번만 사용
  (근접 배치된 거더 사이 공간을 부재로 오인하지 않음).
- **스팬 분할**: 거더=기둥·벽·직교거더, 보=기둥·거더·벽에서 분할. 벽체는 개구부에서만 분리.
- **이름 매칭**: 표기 텍스트 ↔ 가장 가까운 같은 종류 부재(텍스트 방향이 부재와 평행하면 우선).
  미표기 스팬은 같은 연속선의 표기 스팬 이름을 *추정*으로 부여(옵션, 점선 표시).
- 보 춤(D)은 평면도에 없으므로 표기에 `400X700`처럼 적힌 경우만 표시.

## v2.6.1 — 형상 우선 (벽/기둥 구분)
- 레이어보다 **모양**으로 판단: 작고 뭉툭한 외곽선 = 기둥(b×h), 길쭉하거나 꺾인 외곽선 = 벽(두께).
  기둥 레이어에 그려진 벽, 벽선과 이어져 그려진 기둥(선 묶음이 하나로 붙은 경우)도 분리해서 인식.
- 벽선 사이에 그려진 표기 없는 기둥(벽보다 두꺼운 사각형) 인식, 샤프트·덕트 같은 빈 칸은 제외.
- 짧고 두꺼운 벽 조각(예: 600×700)은 기둥으로 판단.
- 평행선 쌍 중 겹친 길이가 간격보다 훨씬 짧은 것(선 끝끼리 짝지어진 가짜 부재)을 버려,
  문 개구부가 메워지거나 샤프트 벽이 사라지던 문제 수정.
- 꺾인 벽은 꺾이는 곳마다 절점으로 분리(모서리 절점 공유). WallGirder는 벽 인식 후 적용되어 벽 위 거더 삭제.
- 2차 검토: '기둥' 레이어인데 내용이 대부분 벽 형상이면 '벽체 형상'으로 바꾸라고 제안.
- 표기 매칭: 형상으로 찾은 기둥보다 도면에 그려진 기둥에 표기를 우선 배정.
