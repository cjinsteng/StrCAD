# StrCAD 수정내역 · 코드 위치

직접 코드를 고칠 때 보는 문서입니다. 수정할 때마다 맨 위에 새 버전을 추가합니다.

- **줄 번호는 그 버전 기준**입니다. 이후 수정으로 밀릴 수 있으니, 함께 적은 **찾기 단어**로 검색하는 게 정확합니다 (VS Code 기준 `Ctrl+F`, 여러 파일은 `Ctrl+Shift+F`).
- 폴더: `strcad_cad_analysis/`
  - `mobile/` : 휴대폰 앱 (HTML·JS·CSS) — APK 도 이 파일들로 만들어짐
    - `index.html` : 화면 뼈대 (버튼·메뉴 배치)
    - `app.js` : 검측점·목록·입력 창·저장 등 거의 전부
    - `sketch.js` : 스케치 (부재·축·자유선·치수·글자, 스케치 목록)
    - `collab.js` : 로그인·협업
    - `newsheet.js` : 도면 추가 (PDF·빈 도면)·축척 맞추기
    - `app.css` : 모양 (글씨 크기·색·간격)
  - `cad_analysis/` : PC 프로그램 (Python)
    - `survey.py` : 조사 용도·항목 정의, 목록 표시
    - `report_out.py` : 손상물량표(엑셀)·사진첩(한글)
    - `app.py` : PC 화면
    - `collab.py` : 협업 서버
  - `android-app/` : APK 포장 (버전 번호 `android/app/build.gradle` 의 versionCode / versionName)
- 앱 버전을 올릴 때 바꾸는 곳: `cad_analysis/__init__.py`, `android-app/android/app/build.gradle`, `mobile/sw.js` 의 `strcad-survey-vNN`

## v2.31.0 (2026-11-27)

1. **그림 스케치 — 넣은 뒤 한 번 끌어서 위치, 길게 눌러 수정 = 손잡이로 크기·회전, 'A 글자' 옆 완료/취소**
   - 넣은 직후 한 번 끌면 이동: `mobile/sketch.js` `function drawImgAt` — 찾기 `끌어서 위치를 잡으세요 (한 번)` (494줄 부근). `st.act = { kind: "move" … }` 로 다음 끌기 한 번만 이동합니다.
   - 길게 누르기 → 수정 → 손잡이 모드: `function itemActions` 안 찾기 `tfStart(sk)` (300줄 부근)
   - 손잡이 모드 함수들 (498~566줄 부근):
     - `function tfGeom`: 상자 계산
     - `function tfHandles` / `function tfHandle`: 손잡이 8개와 회전 손잡이, 누른 손잡이 찾기. 터치 여유는 `bd = 22`(px)
     - `function tfDrag`: 모서리·변 = 크기, ⟳ = 회전, 안쪽 = 이동. 회전은 15° 근처면 딱 맞춥니다 (`Math.abs(sn - a) < 4`)
     - `function tfDraw`: 상자·손잡이 그리기. 손잡이 크기는 `9 : 6.5`
     - `function tfStart` / `function tfEnd`: 시작 / 완료(저장)·취소(되돌림)
     - `function tfButtons`: 'A 글자' 옆 ✔ 완료 · ✕ 취소 · ✎(다시 그리기) 버튼
   - 손잡이 모드일 때 누르기 처리: `function down` 안 찾기 `그림 수정 중: 손잡이` (220줄 부근)
   - 버튼 모양: `mobile/app.css` 찾기 `'A 글자' 옆 완료/취소`
2. **보·벽체 '분리 / 분리안함'**
   - 버튼: `mobile/sketch.js` `function buildSub` — 찾기 `분리" : "분리안함"` (1197줄 부근). 설정값은 `st.split` 이고, `DEF` 에 `split: false` 가 기본입니다.
   - 그린 뒤 나누기: `function finishDraw` 의 `if (st.split) splitWith(c)` (343줄 부근)
   - 나누는 계산 (567~620줄 부근):
     - `function segX`: 두 선 교차
     - `function collinearCuts`: 같은 선 위에 겹칠 때. 허용 오차는 `tol = 5`(mm)
     - `function piecesAt`: 조각 만들기. 50mm 보다 짧은 조각은 만들지 않음 (`minT`)
     - `function splitWith`: 기존 보(벽)와 새 보(벽)를 둘 다 나누고, 똑같이 겹치는 조각은 하나만 남김
   - 같은 종류끼리만 나눕니다 (보는 보끼리, 벽은 벽끼리). 다른 사람 스케치는 나누지 않습니다.

## v2.30.0 (2026-11-27)

1. **스케치 'A 글자' → 스케치해서 그림으로 넣기 (크기·회전)**
   - 버튼: `mobile/sketch.js` `function askText` 안 — 찾기 `스케치해서 넣기` (472줄 부근)
   - 그리기 판: `mobile/app.js` `window.padOverlay` (1581줄 부근)
     - 펜 색·🧽 지우개·되돌리기가 있습니다. 배경이 투명이라 도면이 비쳐 보입니다.
     - '넣기'를 누르면 그린 부분만 잘라서 PNG로 만듭니다 (찾기 `그린 부분만 잘라서`).
     - 지우개 굵기는 `w: 20`, 펜 굵기는 `w: … 3 : 3.5` 입니다.
   - 도면에 넣기: `sketch.js` `function drawImgAt` (480줄 부근)
     - 처음 크기는 `w: Math.round(W * 0.45 / S.view.s)` → 판 너비의 45% 정도로 보이게 들어갑니다.
     - 스케치 항목은 `kind: "img"` 이고 `pts`(가운데)·`w`(가로 mm)·`ar`(세로/가로)·`rot`(회전°)·`img`(PNG)·`strokes`(다시 그리기용 획)를 가집니다.
   - 크기·회전 창: `sketch.js` `function editImg` (488줄 부근). 길게 누르기 → 수정으로 엽니다. 버튼 목록 `["⟲ 15°", 15] …`, `["½ 작게", 0.5] …` 은 여기서 바꿉니다.
   - 그리기: `sketch.js` `function drawOne` 안 찾기 `손으로 그린 그림` (722줄 부근), 그림 불러오기 `function imgOf`
   - 누르기·잡기: `sketch.js` `function hitItem` 안 찾기 `그림: 회전된 사각형 안` (163줄 부근)
   - 목록 이름 '그림': `sketch.js` `const KIND_NM` (14줄)
   - PC 프로그램에는 아직 그림이 표시되지 않습니다 (`cad_analysis/app.py` `_draw_sketches` 에 `img` 처리 없음).
2. **부재 줄 (보/기둥/벽체 + 크기) 화면에 맞춤**
   - `mobile/sketch.js` `function buildSub` — 찾기 `보·기둥·벽체는 왼쪽에 고정` (1066줄 부근)
     - `sub-fix` 칸(보·기둥·벽체)은 고정, `sub-scroll` 칸(폭·단선/복선·자동네임 등)은 좌우로 밉니다. 크기 버튼을 맨 앞으로 옮겼습니다.
   - 모양: `mobile/app.css` 찾기 `보·기둥·벽체 고정` (540줄 부근), 크기 버튼 폭 `#skSub button.val`

## v2.29.0 (2026-11-27)

1. **부재검측 복사 — 부재 종류가 다르면 묻기**
   - `mobile/app.js` `function copyRecTo` (937줄 부근) — 찾기: `복사할 곳 부재 종류가 다르면`
     - 복사할 곳의 부재(스케치/도면)를 보고 종류(기둥 c / 보 b / 벽 w)가 다르면 확인 창을 띄웁니다. '예'면 `copyRecTo(..., { force: true })` 로 내용 그대로 복사하고, '아니요'면 취소합니다.
   - 같은 파일 `function placeAtPoint` (912줄 부근) — 인자 `keepContent` 추가. '예'로 복사할 때는 위치만 옮기고 이름·크기는 바꾸지 않습니다.
   - **원인 수정** `mobile/sketch.js` `function memberAt` (925줄 부근): 화면을 축소해 보면 기둥의 '터치 여유'가 1m 넘게 커져서, 보 위를 눌러도 근처 기둥으로 잡혔습니다. 지금은 보·기둥·벽 중 **가장 가까운 부재**(안쪽이면 0)를 고릅니다. 기둥 내용이 보에 이상하게 들어가던 원인입니다.
2. **이어서 하기 — 보던 화면 그대로**
   - `mobile/app.js` 찾기: `$("#btnResume").onclick` (2250줄 부근)
     - 작업 중이던 파일이 열려 있으면 다시 불러오지 않고 시작 화면만 닫습니다.
   - 같은 곳 아래 `function saveView` / `function restoreView` — 앱을 다시 켰을 때 마지막 도면·확대·위치를 복원합니다. 5초마다, 그리고 앱이 뒤로 갈 때 `localStorage` 의 `lastView` 에 저장합니다.
3. **부재명 세 칸 (종류 · 기호 · 번호)**
   - `mobile/app.js` `const KIND_CODE` (1527줄 부근) — 종류별 기본 기호 (기둥 C, 큰보 G, 작은보 B, 슬래브·바닥 S, 내력벽 W, 조적벽 MW). 여기서 바꾸면 됩니다.
   - 같은 곳 `function nameParts3` / `setNameParts` / `clearNameParts` — 부재명을 세 부분으로 나누고 합칩니다. 저장할 때는 `name` 에도 'G12 큰보'처럼 합쳐서 넣습니다 (PC 호환).
   - 입력 창: `function renderForm` 안 찾기 `class: "row three"` (1467줄 부근) — 기호 버튼의 기본 목록 `["C", "G", "B", …]` 과 번호 목록이 여기 있습니다.
   - 값 고르기: `function pick` 안 찾기 `key === "mkind" || key === "mcode"` (1709줄 부근). 종류를 바꾸면 기호가 자동으로 바뀝니다. 번호는 같은 기호의 '다음 번호'를 제안합니다 (찾기 `다음 번호`).
   - 칸 폭: `mobile/app.css` 찾기 `row.three`
4. **추가사항 스케치 지우개**
   - `mobile/app.js` `function sketchNote` (1587줄 부근) — 찾기 `지우개 = 굵은 흰 선`. 지우개 굵기는 `w: 20` 입니다.
   - 버튼: 같은 함수 안 `🧽 지우개`
5. **스케치 도구줄 — 아이콘만, 크게**
   - `mobile/sketch.js` `function buildOps` (1021줄 부근) — 아이콘 문자(✥ ⌫ ↶ ⊾ 🧲 ▦)를 바꾸려면 여기를 고칩니다. 켬/끔은 누를 때 안내 문구(toast)로 보여줍니다.
   - 크기: `mobile/app.css` 찾기 `스케치 도구줄 아이콘` — `font-size: 22px; min-width: 44px`
